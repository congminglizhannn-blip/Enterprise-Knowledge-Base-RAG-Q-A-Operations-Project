# RAG 最小测试样例

## 权限过滤

1. 创建两个部门 A、B。
2. 分别为两个部门创建知识库和文档 chunk。
3. 使用 A 部门普通用户提问。
4. 期望：SQL 检索仅返回 A 部门 `department_id` 下的 chunk。

## 文本型 PDF

1. 上传文本型 PDF。
2. 期望：解析成功，生成 chunk，状态为 `completed`。

## 扫描 PDF

1. 上传无可提取文本的扫描件 PDF。
2. 期望：状态为 `failed`，错误提示为“扫描件暂不支持，请上传文本型 PDF（OCR 功能开发中）”。

## 流程类问题

问题：`科技成果转化流程怎么走？`

期望：

- DeepSeek prompt 中包含 Mermaid 输出要求。
- 回答包含文字说明。
- 回答包含 `mermaid` 代码块。
- 流程图节点不超过 10 个，节点使用中文。
